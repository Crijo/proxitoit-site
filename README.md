# Site PROXITOIT

Site vitrine de PROXITOIT, charpente, couverture et zinguerie au Creusot (71).

- Contenu et coordonnées : bloc `ENTREPRISE` en haut de `build.js`
- Générer les pages : `node build.js` (écrit dans `site/`)
- Aperçu local : `node .claude/serve.js` puis http://localhost:5173
- Publication : chaque push sur `main` met à jour GitHub Pages
